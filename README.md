# API CRUD - Spring Boot

API REST com operações CRUD usando Spring Boot.

---
🛠️ Tecnologias
-Java 21

-Spring Boot 4.1.1 

-Spring Web MVC

-Spring Data JPA

-Spring Validation

-PostgreSQL

-Maven



---

## 📌 Endpoints da API

| Método | Endpoint | Descrição |
| :--- | :--- | :--- |
| `GET` | `/localhost:8080/products` | Listar todos os itens |
| `GET` | `/localhost:8080/products/{id}` | Buscar item por ID |
| `POST` | `/localhost:8080/products` | Criar um novo item |
| `PUT` | `/localhost:8080/products/{id}` | Atualizar um item existente |
| `DELETE` | `/localhost:8080/products/{id}` | Remover um item |
